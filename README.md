# personal_portfolio
This is my personal portfolio website created as part of my internship task. It showcases my introduction, technical skills, projects, and contact details in a clean and responsive design.

## Features

- Home section with personal introduction
- About Me section
- Technical skills section
- Projects section
- Contact section
- GitHub and LinkedIn links
- Responsive design for desktop and mobile
- Smooth navigation between sections

## Technologies Used

- HTML5
- CSS3
- Google Fonts
